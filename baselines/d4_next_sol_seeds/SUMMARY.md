## 1. 實驗設計

| 項目 | 設定 |
|------|------|
| 拼圖 | v1、v2（12×12，11 塊六格拼圖） |
| 放置 | 全放置（無 soft prune） |
| 封鎖 | 已知解 **D4 對稱**（8 條 blocking） |
| 求解 | Kissat `--seed=1..10`，各找 **1 個**新 SAT 解 |
| 起點 CNF | 固定 `{method}_d4.cnf`（每 seed 獨立跑，不追加 blocking） |
| 驗證 | no-touch；統計 D4 互異解 |

**vs baseline** = baseline 平均求解時間 ÷ 該方法平均（>1 表示較快）。

**原始資料**：

- v1：`baselines/v1/d4_next_sol_seeds/results.json`
- v2：`baselines/v2/d4_next_sol_seeds/results.json`
- 各拼圖摘要：`baselines/{v1,v2}/d4_next_sol_seeds/RESULTS.md`
- CNF 快取：`baselines/{v1,v2}/d4_next_sol_seeds/{method}_base.cnf`、`{method}_d4.cnf`

**重跑求解（重用 CNF）**：

```bash
cd encoding
python3 run_d4_next_sol_seeds.py --puzzle v1 --solve-only
python3 run_d4_next_sol_seeds.py --puzzle v2 --solve-only
```

## 6. 結論（簡報用）

1. **shape（邊角 margin 二元死區）** 在 v1 / v2 皆明顯快於 baseline（**≈2.2×**、**≈1.7×**），且標準差最小、時間最穩。
2. **shape′ 與 shape** base CNF 相同；v2 上逐 seed 幾乎同秒，平均 6.67 vs 6.63 s。
3. **shape″** 強烈依賴拼圖：v1 求解慢於 baseline（0.87×）；v2 略快（1.09×）但仍輸 shape，且 CNF 生成最久（39–67 分鐘）。
4. **baseline** 在兩拼圖上都有離群 seed（v1 seed 3/7；v2 seed 1/5/9），拉高标准差；shape 較少出現此現象。

## 8. Learned Dead-Pocket（Formal + AI）

> 詳細報告：[`baselines/learned_shape/REPORT.md`](../learned_shape/REPORT.md)

AI 預篩 placement pair，僅對高分候選呼叫 formal `has_dead_pocket` oracle；**僅 oracle 確認後才加子句**（sound）。

### v2（K\* = 50%，clause recall 99.8%）

| 方法 | 求解平均 | vs baseline | CNF 產生 (s) |

## 9. 注意事項

- 絕對秒數 **不宜跨 v1 / v2 直接比較**（拼圖難度不同）。
- 本表為 **10 seed 單次量測**；倍率宜表述為「約 X×」而非精確常數。
- CNF 產生為 **一次性離線成本**；表中「求解平均」不含 CNF 生成時間。
